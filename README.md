# AWS Cloud Network Labs

Hands-on AWS networking labs focused on VPC design, routing, validation, and cloud network operations.

## Labs

### [Lab 01: Multi-AZ VPC Foundation](labs/01-vpc-foundation/)

Built and validated a dedicated AWS VPC across two Availability Zones with:

- Two public subnets
- Two private subnets
- Internet gateway
- Separate public and private route tables
- Automated deployment, validation, and cleanup scripts

More labs will be added as the repository develops.
